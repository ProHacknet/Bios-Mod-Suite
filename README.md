BIOS Mod Suite 🛠️⚡
Herramienta automatizada en Python para auditar e inyectar modificaciones en memorias NVRAM (UEFI). Diseñada específicamente para evadir bloqueos en placas Apollo Lake (J3355) y desbloquear límites de energía (TDP 15W) y VRAM.

⚠️ Advertencia / Disclaimer: Esta herramienta manipula memoria de bajo nivel (SMI/MMIO). Su uso incorrecto puede causar un "Brick" irrecuperable en la placa base. El autor no se hace responsable por daños al hardware. Úsalo bajo tu propio riesgo.
